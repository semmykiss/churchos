## Deviations + why

- **Kiosk org include**: the finding suggested `event.campus.org`, but `Event.campusId` is a **plain column** (no Prisma relation in the schema), so the include chain doesn't exist. Resolved the org directly by `cs.orgId` (`findFirst({ where: { id: cs.orgId, deletedAt: null } })`) — same guarantee, documented in code.
- **`expiringSoonTotal` population**: counted over the same filtered set as the list (active/trial within 30d). The current `expiringSoon` list carries **no `take`/slice** (nothing to "keep"), so `total === list.length` today; the total is computed pre-truncation so a future `take` on the list cannot shrink it.
- **Idempotency placeholder detection**: AES-GCM uses a random IV, so the placeholder can't be found by ciphertext comparison — the claim row stores `encryptField("{}")` and replay compares **decrypted plaintext** to `"{}"`. Decrypt-failure on an unexpired populated row releases the claim and re-claims once (finding 4's "treat as absent → re-execute"), guarded against loops.
- **Limiter bounds applied to `public-forms.ts` submit log and `onboarding.ts` signup buckets** in addition to the three named maps — finding 10 says "bound every in-memory limiter map", and both live in files I own.
- **`issueLicense` P2002 catch**: added a race backstop mapping unique-violation to the same conflict message (create-only means the DB constraint is the final arbiter; mirrors `createTenant`).
- **setTenantStatus return**: returns `{ id, status }` (the set values) instead of the pre-update-fetched row — identical JSON shape, avoids a re-read after `updateMany`.

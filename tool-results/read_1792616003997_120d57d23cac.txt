     1→// ChurchOS — Prisma schema (SQLite adapter)
     2→// NOTE: The original spec requested Supabase/PostgreSQL. This sandbox environment
     3→// is restricted to SQLite via Prisma, so we adapt: enums become String with app-level
     4→// validation, arrays become Json, and RLS is enforced in the application permission layer
     5→// (lib/permissions.ts) instead of database RLS policies. See README "Assumptions".
     6→
     7→generator client {
     8→  provider = "prisma-client-js"
     9→}
    10→
    11→datasource db {
    12→  provider = "sqlite"
    13→  url      = env("DATABASE_URL")
